# Parche

Reserva la cancha. Arma el parche.

Marketplace de reservas deportivas: los propietarios publican sus sedes y canchas,
y los clientes buscan por deporte, modalidad y zona, reservan y completan su equipo
con partidos abiertos.

Proyecto final de Bases de Datos II.
